# Подарки и тикеты

Каталог содержит 170 интерпретаций LChat предметов, видимых в предоставленной записи. Цены указаны в тикетах LChat и не копируют цены Telegram. Для части подарков используются сгенерированные иллюстрации, для остальных — Unicode-эмодзи. Иллюстрации созданы ИИ и не являются ресурсами Telegram; точного совпадения нет, часть мелких предметов на записи невозможно уверенно распознать.

Администраторы выдают тикеты и галочки на странице `rewards.php#manage`. Оплата и автоматическое пополнение не подключены. Подарок можно отправить из профиля личного чата или из каталога. Каждая покупка создаёт отдельный экземпляр с уникальным идентификатором и определяемым им узором. При обновлении ранее купленные подарки и балансы сохраняются.

Каталог предназначен для отправки подарков, а не для перепродажи. Объявления пользователей, торги и вывод средств не реализованы.

Таблицы создаются существующей системой миграции при первом обращении. Перед обновлением создайте резервную копию базы. Изолированная проверка с установленным PHP и включённым `pdo_sqlite`:

```sh
php tests/gifts-smoke.php
```
