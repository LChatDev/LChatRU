# Бесплатные туннели и частные сети

Пошаговая настройка и управление — в [PORT_TOOLS.md](PORT_TOOLS.md).

| Инструмент | Назначение | Ограничения |
| --- | --- | --- |
| [Cloudflare Tunnel](https://developers.cloudflare.com/tunnel/) | Публикация локального сайта по HTTPS без входящих портов. | Подходит для сайта; не следует считать, что он открывает UDP-диапазон TURN. |
| [Playit.gg](https://playit.gg/) | Туннели для игр и других серверов. | Протоколы зависят от тарифа; по [документации](https://playit.gg/support/playit-scpsl-server/) для TCP сейчас нужен Premium. Проверьте поддержку UDP и диапазонов. |
| [Tailscale](https://tailscale.com/pricing) | Частная сеть между устройствами. | Личный тариф бесплатный; участникам нужен доступ к сети и обычно клиент на устройстве. |
| [ngrok](https://ngrok.com/pricing) | Публикация локального HTTP или TCP. | Есть лимиты; [для TCP нужна проверка банковской карты](https://ngrok.com/faq). |
| [Tailscale Funnel](https://tailscale.com/docs/features/tailscale-funnel) | Публичный HTTPS для локального сайта; посетителям клиент не нужен. | Доступен на бесплатном тарифе; применяются ограничения имени `*.ts.net`, TLS-портов и скорости. |
| [LocalTunnel](https://github.com/localtunnel/localtunnel) | Временный публичный HTTP/HTTPS-адрес для разработки. | Бесплатный публичный сервер; адрес и доступность могут меняться. Нужен Node.js; TURN relay не предоставляется. |
| [localhost.run](https://github.com/localhost-run/site/blob/main/docs/cli.md) | Доступ к локальному сайту через обратный SSH-туннель. | Проверьте условия бесплатного доступа и своего домена; подходит для теста сайта, не TURN UDP. |
| [zrok](https://blog.openziti.io/introducing-zrok-v2-0) | Публичный или частный доступ через готовый или собственный сервер. | Бесплатный сервис имеет лимиты и может показывать промежуточную страницу; проверьте совместимость API. |
| [bore](https://github.com/ekzhang/bore) | Простой TCP-туннель, включая публичный `bore.pub`. | Нет встроенного HTTPS; одного TCP для UDP relay TURN недостаточно. Доступность публичного сервера не гарантирована. |
| [frp](https://github.com/fatedier/frp) | Собственный обратный TCP/UDP-прокси. | Программа бесплатна, но нужен доступный из интернета сервер; для TURN нужны правильные адреса и диапазон портов. |
| [Chisel](https://github.com/jpillora/chisel) | Собственные TCP/UDP-туннели. | Нужен публичный сервер; для TURN проверьте проброс UDP и relay-портов. |
| [Обратный туннель OpenSSH](https://man.openbsd.org/ssh#R) | Проброс локального TCP-сервиса через свой SSH-сервер. | Нужен доступный SSH-сервер; обычный обратный SSH-туннель не открывает UDP-диапазон TURN. |

## Быстрая проверка на Windows

Сначала запустите PHP-сайт на `127.0.0.1:8365`. LocalTunnel даст временный адрес сайта; сначала установите Node.js:

```cmd
npx localtunnel --port 8365
```

Для Tailscale Funnel установите Tailscale **на серверный ПК**, войдите, включите Funnel по документации и выполните:

```cmd
tailscale funnel 8365
```

Посетителям публичного Funnel клиент не нужен. Для частной сети Tailscale клиент обычно нужен участникам. Эти туннели для сайта не предоставляют TURN relay. Временные адреса неудобны для постоянного `public_url` и рабочего сервиса.

Для публичного сайта LChat Cloudflare Tunnel может дать HTTPS. Для TURN нужны доступные порт подключения и UDP-диапазон relay; один HTTP или TCP-туннель их не заменяет. См. [CALLS.md](CALLS.md). Условия и тарифы меняются; проверьте их у провайдера. Перечисленные варианты не проверены на этом развёртывании LChat.
