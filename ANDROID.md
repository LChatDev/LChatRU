# LChat для Android

Нативное приложение поддерживает регистрацию, личные чаты, группы, каналы, файлы, голосовые сообщения, клавиатуры ботов и голосовые интернет-звонки. Это нативные экраны, а не WebView; оформление Telegram Web A относится к сайту и не встроено в APK.

## Установка

Скачайте **LChat-2.0.9-universal.apk** на [странице релиза](https://github.com/LChatDev/LChat/releases/tag/android-v2.0.9). Это один APK, а не набор split-пакетов. Его можно установить поверх версии 2.0.3: имя пакета и сертификат подписи совпадают.

- Android 8.0 и новее (минимальный SDK 26, целевой SDK 35); ARM64, ARMv7, x86 и x86_64.
- Пакет `su.lbs.lchat`, версия `2.0.9`, код версии `20`.
- Адрес по умолчанию — `https://chat.lbs.su/`; другой совместимый сервер можно указать в меню.
- Разрешите микрофон и уведомления. Аккаунт Telecom не нужен. На сервере нужны HTTPS и совместимый мобильный API; TURN настраивает администратор.

В релизе есть файл `.apk.sha256` с контрольной суммой. Для проверки в PowerShell:

```powershell
Get-FileHash .\LChat-2.0.9-universal.apk -Algorithm SHA256
```

## Звонки и ограничения

Звонок работает в отдельном фоновом процессе с управлением из уведомления. Входящие звонки и сообщения получают коротким опросом, без FCM. Энергосбережение Android может задержать опрос или завершить процесс; после принудительной остановки или перезагрузки откройте приложение снова. Нативное видео и демонстрация экрана не поддерживаются.

Для релиза проверены CRC архива, контрольные суммы DEX, четыре архитектуры, манифест, выравнивание и подпись APK, в том числе для Android 12/12L. Сертификат совпадает с 2.0.3. Физического телефона для проверки установки, микрофона и фоновых звонков не было; совместимость со всеми устройствами не гарантируется. В 2.0.9 на устройствах Samsung используется программная обработка звука, а диагностика показывает адреса сбоя в библиотеке. Это тестовый вариант: причина сбоя ещё не установлена, звонки сборки не проверены на телефонах.

## Сборка исходников на Windows

Исходники Android находятся в [репозитории LChat](https://github.com/LChatDev/LChat/tree/main/android). Потребуются JDK 21 (`javac`, `java`, `jar`, `keytool`), Android SDK Platform 35 (`android.jar`), Build Tools 35.0.0 (`aapt2`, `zipalign`, `lib/d8.jar`, `lib/apksigner.jar`), Node.js и распакованный AAR `io.github.webrtc-sdk:android:150.7871.01` с `classes.jar` и `jni/{arm64-v8a,armeabi-v7a,x86,x86_64}/libjingle_peerconnection_so.so`.

Из корня клонированного репозитория LChat выполните, заменив пути своими:

```powershell
.\android\build.ps1 -JavaHome 'C:\tools\jdk-21' -BuildTools 'C:\tools\android-sdk\build-tools\35.0.0' -AndroidJar 'C:\tools\android-sdk\platforms\android-35\android.jar' -WebRtcDir 'C:\tools\webrtc-150.7871.01'
node .\android\tests\apk-integrity.cjs .\android\LChat-2.0.9-universal.apk
```

Скрипт создаёт `LChat.apk`, версионный APK и SHA-256. Новый клон создаёт свой ключ в `android/signing/`: сборка с ним не обновит официальный APK поверх установки. Храните свой ключ и пароль закрыто и сохраняйте резервную копию для будущих обновлений. Официального ключа в репозитории нет.

Исходники Android распространяются по GPL-3.0. Лицензии WebRTC находятся в `licenses/` и включены в APK. Данные базы, ключ установки, токены ботов и постоянный секрет TURN в APK не включены.
