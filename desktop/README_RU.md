# LChat для Windows

Клиент для Windows 10/11 x64 с актуальным интерфейсом https://chat.lbs.su. Это настольная оболочка веб-клиента на Electron; Android использует отдельные нативные экраны Java.

Скачайте `LChat-1.0.0-Windows-x64.exe` из [релиза](https://github.com/LChatDev/LChat/releases/tag/clients-2026.11.20). Запускается без установки, Node.js не нужен. EXE не подписан сертификатом издателя. Настройки и сессия сохраняются в профиле пользователя Windows; для работы нужен интернет.

Закрытие окна сворачивает приложение в трей. Двойной щелчок по значку возвращает окно. Для полного завершения выберите «Выход (завершить звонок)» в трее. Не закрывайте процесс во время разговора. Микрофон, камера и уведомления запрашиваются отдельно. Автозапуск не включается. Внешние ссылки открываются в браузере после подтверждения. Демонстрация экрана пока не подключена.

## Сборка

Установите Node.js с npm. В каталоге `desktop` выполните:

```powershell
npm ci
npm test
npm run build
```

Результат: `dist/LChat-1.0.0-Windows-x64.exe`. Зависимости зафиксированы в `package-lock.json`. Используются sandbox, context isolation, отключён Node.js в веб-странице. Серверные конфиги и секреты в приложение не включаются.

## Проверка выпуска

Проверены правила навигации/разрешений, запуск упакованного приложения, загрузка страницы входа, изоляция Node.js и снимок экрана. Переписка под аккаунтом, звонок между двумя устройствами, камера и работа при длительном сне Windows в этой среде не проверялись. Изменения сервера отображаются при следующей загрузке страницы; обновления самого Electron требуют новой сборки.
