# LChat для Android — 3.0.0

Нативные экраны Java и голосовые звонки WebRTC для PHP-сервера LChat. Сервер по умолчанию: https://chat.lbs.su/. Android 8.0+, пакет `su.lbs.lchat`, версия 3.0.0 / код 30. Универсальный APK: ARM64, ARMv7, x86 и x86_64. Пиксельное оформление сохранено.

Скачать APK (previous binary withdrawn / прежняя сборка удалена) · [English](README.md) · [Изменения и проверки](RELEASE_3.0.0.md)

Установите поверх предыдущего официального APK: подпись сохранена. Разрешите микрофон и уведомления. Аккаунт приложения «Телефон» не нужен. В манифест добавлено `ACCESS_NETWORK_STATE`: это обычное разрешение, оно выдаётся при установке и предотвращает воспроизведённый вылет монитора сети WebRTC.

## Новые звонки

Служба Android, очередь нативного аудио, HTTP-запросы, управление звуком и состояние разговора теперь разделены. Сетевой запрос не останавливает обработку аудио. Поздний ответ сервера не возобновляет завершённый звонок. Подключение хранится в атомарном журнале с блокировкой между процессами; ожидание подтверждения от экрана удалено.

Доступны микрофон, динамик/обычный выход, выбор доступного входного устройства, восстановление ICE, сворачивание и возврат через уведомление. Таймер начинается при соединении с участником. Видео и показ экрана в нативном клиенте не реализованы. Для разных сетей нужен доступный TURN; его временные данные отдаёт существующий PHP-сервер. HTTPS обязателен. Новая серверная служба не нужна, рабочий конфиг не заменяется.

Входящие проверяются видимой фоновой службой через опрос сервера, без FCM. Android может задерживать опрос в глубоком сне; после принудительной остановки откройте приложение снова. Активный разговор использует уведомление микрофонной foreground-службы и блокировку сна процессора. Работа реальной Bluetooth-гарнитуры, ограничения батареи и глубокий Doze требуют отдельных испытаний на телефоне.

Чаты, группы, каналы, боты, ответы, реакции, редактирование и удаление, вложения и голосовые сохранены. У нативной загрузки файлов остаётся прежний лимит; возможности и лимиты сайта могут отличаться.

## Сборка на Windows

Нужны JDK 21+, Python и Node.js для независимой проверки APK. Из корня репозитория:

```powershell
python android/setup-tools.py
.\android\build.ps1 -JavaHome 'C:\tools\jdk-21' -BuildTools 'C:\LChat\android\sdk\build-tools\android-15' -AndroidJar 'C:\LChat\android\sdk\platform\android-35\android.jar' -WebRtcDir 'C:\LChat\android\sdk\webrtc-150.7871.08'
node android/tests/apk-integrity.cjs android/LChat-3.0.0-universal.apk
```

Замените пути своими. Скрипт загружает закреплённые SDK Google и WebRTC из Maven и сверяет контрольные суммы. Результат: `LChat.apk`, APK с версией и файл SHA-256. Сборка проверяет подпись и выравнивание, в том числе правила Android 12/12L.

Сохраняйте собственную закрытую папку `android/signing/`: без прежнего ключа нельзя установить обновление поверх своей старой сборки. Новый checkout создаёт другой ключ. Не публикуйте подпись, пароль, SDK и серверные секреты. Лицензии библиотек включены в APK и каталог `licenses/`.
