# LChat RU

> **Предупреждение:** LChat полностью создан с помощью искусственного интеллекта. Проект использует сторонние компоненты, перечисленные в документации и лицензиях.

Русская версия самостоятельного PHP-мессенджера LChat: личные чаты, группы, каналы, файлы, голосовые сообщения, звонки и API ботов. Это самостоятельный сервис со своей базой пользователей.

## Установка

1. Подготовьте PHP 8.2+, расширения `pdo_mysql`, `mbstring`, `fileinfo`, `curl`, `gd`, MySQL/MariaDB и Apache с `mod_rewrite`. Для звонков нужен HTTPS.
2. Загрузите файлы проекта в одну папку сайта, сохранив скрытые `.htaccess`. Скопируйте `config.example.php` в `config.php` и укажите данные своей базы, HTTPS-адрес сайта, название, `initial_admin_username` и случайный ключ установки не короче 32 символов.
3. Откройте `install.php` через HTTPS, введите ключ и создайте таблицы. Зарегистрируйте пользователя, указанного в `initial_admin_username`, и войдите в `admin.php`.
4. Удалите `install.php` с сервера и очистите ключ установки. Папки `data` и `files` должны быть доступны PHP для записи. Не публикуйте `config.php`, содержимое этих папок и резервные копии.

Владелец может менять название, регистрацию, лимит участников и параметры TURN в админке. Эти значения сохраняются в базе поверх конфига; кнопка сброса возвращает настройки из конфига. Пароль базы, адрес сайта и настройки сессии остаются в `config.php`.

Для надёжных звонков между разными сетями может понадобиться отдельный TURN-сервер. Для него необходимы доступные порт подключения и диапазон UDP-портов для передачи аудио и видео. Один обычный TCP-туннель не заменяет диапазон портов.
